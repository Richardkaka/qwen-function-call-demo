## 🔐 统一API密钥配置
支持**灵积**、**千问云**双平台密钥共存，二选一配置即可，所有工具共用同一套密钥配置。

### 方式1：.env 文件配置（推荐，密钥安全不外露）
在所有脚本**同级目录**新建 `.env` 文件，写入对应密钥：
```env
# 阿里灵积平台密钥（PRD评审、函数调用、OCR工具通用）
DASHSCOPE_API_KEY=你的灵积API密钥
# 千问云平台密钥（备用/切换接口使用）
QIANWEN_API_KEY=你的千问云API密钥
```

### 方式2：代码内直接填写（新手临时使用）
打开对应 `.py` 脚本，找到 `API_KEY = ""` 配置项，直接填入你的密钥。

> 提示：`.env` 文件属于本地私有配置，请勿上传至 GitHub。

# 一、AI PRD 智能全维度评审工具
✨ 基于AI大模型的自动化PRD产品需求文档评审工具，无需人工筛选评审角色，支持单份/多份文档批量评审，一键输出专业评审报告。

## 核心功能
- 📄 **多格式兼容**：支持 `PDF / DOC / DOCX / MD / TXT / XLS / XLSX` 主流办公文档
- 📁 **批量自动扫描**：自动检索脚本同级目录下所有支持格式文件，无需手动填写文件路径
- 🤖 **AI智能角色推荐**：结合文档内容，自动匹配适配的评审角色
- 👥 **全角色评审**：包含产品、研发、设计、测试、合规、运维等18类专业评审角色
- 📊 **结构化报告**：自动生成 Markdown 格式报告，包含问题分级、数据统计、整改建议

## 支持的评审角色
### 基础必选角色
产品经理(PM)、前端开发(FE)、后端开发(BE)、测试工程师(QA)、UI设计师、UX设计师、数据分析师(DA)、客服代表(CS)、法律合规(LEGAL)

### 智能可选角色
技术架构师、安全工程师、运维工程师、大数据工程师、算法工程师、微信小程序审核专员、应用商店审核专员

## 快速使用
1. 将待评审文档放到脚本**同级文件夹**；
2. 终端进入项目目录，执行运行命令：
```bash
python3 prd_review_agent.py
```
3. 运行完成后，同级目录会自动生成 `PRD评审报告_文档名_时间戳.md` 报告文件。

## 问题分级标准
- P0-阻断：致命问题，必须修复才可进入下一阶段
- P1-严重：高危问题，开发前务必完成修复
- P2-一般：常规问题，可在开发过程中同步优化
- P3-建议：优化类建议，可按需整改

# 二、通义千问 FunctionCall 实战（城市薪资演示）
📌 大模型函数调用入门案例，完整演示 **意图识别 → 工具调用 → 结果整合** 标准开发流程，用于学习通义千问 FunctionCall 能力。

## 核心功能
- 内置国内多座城市模拟人均薪资数据；
- 大模型自动识别用户提问意图，自主判断是否调用本地工具函数；
- 自动解析调用参数，执行本地逻辑后将结果回传给大模型二次整理；
- 非薪资类问题，直接正常对话回复，不触发工具调用；
- 注：所有薪资数据均为**模拟数据**，仅用于技术学习演示。

## 快速使用
```bash
python3 city_salary_demo.py
```

# 三、图片文本智能提取工具（OCR）
🖼️ 分为**本地图片**、**在线图片**两个独立脚本，依托AI视觉能力精准提取图片内文字，支持批量处理。

## 3.1 本地图片文本提取
脚本：`img_extra_agent_local.py`
### 核心功能
- 支持 `jpg / png / jpeg` 等常见本地图片格式；
- 批量识别同级目录下所有图片；
- 提取结果为纯文本，可直接复制编辑。

### 快速使用
1. 将需要识别的本地图片放到脚本**同级文件夹**；
2. 执行命令：
```bash
python3 img_extra_agent_local.py
```

## 3.2 在线图片文本提取
脚本：`img_extra_agent_online.py`
### 核心功能
- 支持公开可访问的图片URL链接；
- 输入链接即可远程提取图片文字，无需下载图片；

### 快速使用
```bash
python3 img_extra_agent_online.py
```
运行后根据终端提示，填入在线图片链接即可完成识别。

## ❓ 常见问题 FAQ
1. **提示未读取到 API Key / 密钥错误**
   - 检查 `.env` 文件名称、路径是否正确，密钥内容**无多余空格、换行符**；
   - 切换接口时，确认密钥与对应大模型平台匹配。

2. **提示 `FileNotFoundError` 文件不存在**
   - 确认待处理文件（文档/图片）与脚本在同一目录；
   - 检查文件后缀是否为工具支持的格式。

3. **运行报错 `can't find '__main__' module`**
   - 误执行了文档/图片文件，仅运行后缀为 `.py` 的脚本文件即可。

4. **接口 404 / 调用失败**
   - 核对接口地址、模型名称配置，确认密钥账户状态正常。

5. **Excel / 图片解析异常**
   - 重新执行顶部的依赖安装命令，补全 `pandas`、`openpyxl`、`pillow` 等依赖库。
