
# AI PRD 智能全维度评审工具
✨ 基于AI大模型的自动化PRD产品需求文档评审工具，无需人工判断参与角色，一键生成专业评审报告，支持**单/多份文档**批量评审

## 核心功能
- 📄 **超多格式兼容**：支持 `PDF / DOC / DOCX / MD / TXT / XLS / XLSX` 主流文档格式
- 📁 **批量自动扫描**：无需手动配置文件路径，自动读取脚本同级目录下所有支持文档，单文件/多文件均可处理
- 🤖 **AI智能角色推荐**：自动分析PRD内容，智能匹配需要参与评审的角色，免去人工选择
- 👥 **全角色评审**：覆盖产品、前端、后端、测试、UI/UX、安全、合规、平台审核等18种专业角色
- 📊 **结构化报告输出**：自动生成标准 Markdown 评审报告，问题分级、数据统计清晰直观
- 🔐 **双重密钥配置**：支持代码直填密钥（小白）/ `.env` 环境变量（进阶/开源）两种模式，安全不泄露
- ⚡ **开箱即用**：简单配置即可运行，无复杂额外配置

## 支持的评审角色
### 基础必选角色
产品经理(PM)、前端开发(FE)、后端开发(BE)、测试工程师(QA)、UI设计师、UX设计师、数据分析师(DA)、客服代表(CS)、法律合规(LEGAL)

### 智能可选角色
技术架构师、安全工程师、运维工程师、大数据工程师、算法工程师、微信小程序审核专员、应用商店审核专员

## 快速开始
### 1. 安装环境依赖
执行以下命令安装全部依赖库（包含文档解析、AI调用、环境变量、Excel读取全套依赖）
```bash
pip3 install langchain langchain-community pydantic python-docx pypdf dashscope python-dotenv pandas openpyxl xlrd
```

### 2. 配置通义千问 API 密钥
本项目提供**两种配置方式**，二选一即可，适配不同使用场景：

#### 方式一：代码内直接填写（小白推荐，简单快捷）
打开主脚本 `prd_review_agent.py`，找到配置区的 `API_KEY` 变量，填入你的密钥：
```python
# 小白直接在此填写API Key，进阶用户使用.env文件
API_KEY = "你的通义千问API密钥"
```

#### 方式二：.env 文件配置（进阶/开源推荐，密钥不泄露）
1. 在 **脚本同级目录** 新建名为 `.env` 的文件（Mac 该文件默认隐藏，正常创建即可）
2. 在 `.env` 中写入以下内容，替换为你的真实密钥：
```env
DASHSCOPE_API_KEY=你的通义千问API密钥
```
> 注意：`.env` 文件**请勿上传至 GitHub**，项目已配置 `.gitignore` 自动忽略。

### 3. 准备待评审文档
1. 将你需要评审的文档（支持 `doc / docx / pdf / md / txt / xls / xlsx`）**直接放到脚本同级文件夹**
2. ✅ 无需修改代码、无需固定文件名，任意命名均可；支持同时放入**一份或多份**文档批量评审

### 4. 运行工具
打开终端，进入项目文件夹后执行运行命令：
```bash
python3 prd_review_agent.py
```

### 5. 查看评审结果
1. 程序会自动遍历目录内所有文档，逐个执行评审
2. 每一份文档都会独立生成一份 `PRD评审报告_文档名_时间戳.md` 报告
3. 报告内包含：文档信息、问题统计、分级问题明细、最终评审结论、下一步整改建议

## 技术栈
- Python 3.8+
- LangChain：大模型调用与链路编排
- 通义千问（qwen-max/qwen-plus）：AI 推理与内容分析
- python-docx：Word 文档解析（doc/docx）
- pypdf：PDF 文档解析
- pandas + openpyxl + xlrd：Excel 表格解析（xls/xlsx）
- python-dotenv：环境变量读取（密钥安全配置）

## 使用说明
1. 文档放置规则：所有待评审文件必须和 `prd_review_agent.py` 放在**同一个文件夹**
2. 角色匹配：AI 会根据文档内容自动筛选评审角色，无需人工干预
3. 问题分级标准：
   - P0-阻断：致命问题，必须修复才能进入下一阶段
   - P1-严重：高危问题，开发前务必修复
   - P2-一般：常规问题，可在开发过程中优化
   - P3-建议：优化建议，按需整改
4. 输出报告：Markdown 格式报告可直接用于团队同步、评审归档、开发验收

## 常见问题 FAQ
1. **提示 `FileNotFoundError` 文件不存在？**
   - 确认文档和 Python 脚本在**同一个文件夹**；
   - 确认文件后缀为支持格式（doc/docx/pdf/md/txt/xls/xlsx），无格式错误。

2. **提示密钥错误/未读取到 API Key？**
   - 检查密钥是否复制完整，无多余空格、换行；
   - 使用 `.env` 方式时，确认文件和脚本同级、文件名为 `.env`（前方带英文点）。

3. **运行命令报错 `can't find '__main__' module`？**
   - 错误原因：误执行了 Word/PDF 等文档；
   - 解决：仅运行后缀为 `.py` 的脚本文件 `prd_review_agent.py`。

4. Excel 文件读取异常？
   - 重新执行依赖安装命令，确保 `pandas / openpyxl / xlrd` 安装成功。
